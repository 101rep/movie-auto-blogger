# Compound Engineering Learning Loop Skill

## Trigger Conditions
Activate this skill whenever a bug, exception, performance bottleneck, or operational failure is diagnosed and resolved.

## Compounding Cycle
Whenever an issue occurs:

1. **Issue Identification:** Document the observed symptoms, platform, error trace, and conditions.
2. **Root Cause Analysis (RCA):** Deeply investigate why it failed at the architectural or mechanical level (not just superficial symptoms).
3. **Fix Implementation:** Apply a robust, permanent fix that addresses the root cause.
4. **Documentation:** Record the complete incident in `/AI_ENGINEERING/debugging_history.md`.
5. **Knowledge Update:** Update `/AI_ENGINEERING/engineering_memory.md` with new ADRs or constraints.
6. **Future Prevention:** Convert the lesson into an automated test or a strict code review rule in `/AI_ENGINEERING/code_review_rules.md` so the mistake can never repeat.
