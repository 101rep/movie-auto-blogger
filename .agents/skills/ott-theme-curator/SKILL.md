# OTT Theme Curator (OTT 테마별 영화 추천 스킬)

## 1. 개요 및 목적
하루 1개의 테마 중심 영화 큐레이션 콘텐츠를 생성합니다. (일일 3회차: 18:00 KST 슬롯)
"오늘 저녁 넷플릭스에서 긴장감 넘치는 스릴러를 보고 싶다"와 같은 명확한 상황/분위기 니즈를 충족시킵니다.

## 2. 엄격 준수 규칙 (Non-Negotiable Guardrails)
1. **국내 서비스 검증 필수**: 특정 OTT(넷플릭스, 디즈니+, 티빙 등)에서 볼 수 있다고 명시하는 경우, 국내 라이선스 제공 여부가 사전에 확인된 작품만 포함합니다. 확인되지 않은 작품을 특정 OTT 독점작으로 소개하지 않습니다.
2. **과장된 수식어 배제**: "인생 최고의 영화", "모두가 경악한" 등의 자극적인 클릭베이트 수식어를 지양하고, 영화의 실제 톤앤매너(무거움, 경쾌함, 잔잔함)를 정직하게 서술합니다.
3. **작품 간 명확한 분위기 대조**: 추천 작품들이 서로 겹치지 않고 다채로운 매력을 지니도록 분위기/긴장감 비교표를 의무적으로 제공합니다.
4. **Anti-Cliche Guard**: 상투적인 서두와 마무리 배제.

## 3. 글의 표준 7단계 구성
1. **테마 중심 제목**: `[플랫폼] + [테마/분위기] 추천 영화 [N]편: [핵심 감상 매력 요약]`.
2. **대표 히어로 이미지**: 테마 분위기를 대변하는 고해상도 백드롭.
3. **엄선 추천작 3~5편 리스트**: 각 작품별 선정 사유와 테마 정합성.
4. **작품별 기본 정보와 줄거리**: 개봉일, 감독, 출연, 러닝타임, 스포일러 없는 플롯.
5. **작품별 감상 포인트**: 테마에 부합하는 명장면 또는 연출적 성취.
6. **장르 및 분위기 비교표**: 톤(어두움 vs 밝음), 템포(빠름 vs 느림), 몰입도 비교.
7. **취향에 따른 작품 선택 가이드**: "가벼운 킬링타임 vs 묵직한 심리전" 맞춤 권장.
