3. 보안 관리 & 계정 보호 수칙 (Security Guard)

본 자동화 프로그램은 관리자 메인 비밀번호를 직접 사용하지 않고 워드프레스의 독립된 애플리케이션 비밀번호를 통해 REST API로 통신합니다. 필요 시 워드프레스 관리자 → [사용자] → [프로필]에서 특정 키만 언제든 즉시 폐기/재발급할 수 있습니다.

OpenAI Platform(Usage Limits)에서 월별 사용 한도(예: $5~$10)를 지정해 두시면 예기치 않은 과금을 100% 차단할 수 있습니다.

OpenAI(Primary)와 Google Gemini(Fallback)가 이중화되어 있어, 한쪽 엔진에 할당량 초과나 일시적 장애가 발생해도 0초 만에 예비 엔진으로 무중단 자동 전환됩니다.
4. 프로그램 상세 사용 설명서 & 워드프레스 예약 발행 매뉴얼
User Manual & Workflow
4.1 전체 자동화 파이프라인 흐름도 (End-to-End Workflow)
1단계 🎬 TMDB 영화 데이터 수집 최신 박스오피스 & OTT 인기작 메타데이터(포스터, 줄거리, 출연진 등) 자동 취합
2단계 ⭐ 평점 & 예고편 실시간 결합 네이버 실관람객 평점 스크래핑 + 유튜브 공식 예고편 영상 자동 매칭
3단계 🤖 AI 심층 리뷰 & 템플릿 결합 SEO 황금 제목, 넷플릭스 다크 매거진 고대비 템플릿(상징성, 복선, FAQ) 생성
4단계 📅 WP 예약 발행 & IndexNow 지정 간격으로 워드프레스 미래 시간 예약 + 네이버/빙 검색 로봇 즉시 호출
4.2 대시보드 버튼별 기능 상세 백과 (무엇을 누르면 어떻게 되는가?)
버튼 명칭 처리 방식 누르면 내부에서 일어나는 일 (상세 프로세스) 추천 사용 상황
전체 자동화 파이프라인 즉시 실행 원클릭 원스톱 [수집 ➔ 선별 ➔ AI 작성 ➔ 템플릿 렌더링 ➔ 품질 검수 ➔ 워드프레스 예약 발행 ➔ IndexNow 핑] 전 과정을 백그라운드에서 한 번에 일괄 수행합니다.
설정에 지정된 일일 발행 편수(기본 2편)만큼 자동으로 워드프레스 예약 캘린더에 포스팅을 등록합니다. 		오늘치 포스팅을 지금 바로 1초 만에 예약 채워두고 싶을 때
영화 수집 수동 1단계 TMDB API로부터 현재 상영 중인 최신 영화 및 개봉 예정작 목록 10편을 가져와 내부 데이터베이스에 후보군으로 등록합니다. 어떤 영화들이 있는지 목록만 먼저 둘러보고 싶을 때
AI 초안 생성 수동 2단계 수집된 특정 영화 1편을 선택하여 Gemini AI 엔진이 검색 의도에 맞춘 블로그 전문 리뷰 원고를 작성하고, 상태를 [생성 완료 (APPROVED)]로 전환합니다. 내가 원하는 특정 영화만 골라서 리뷰 글을 작성하고 싶을 때
미리보기 & 편집 수동 3단계 작성된 글이 실제 워드프레스 블로그에서 독자에게 어떻게 보여질지(넷플릭스 다크 테마) 완벽한 브라우저 화면으로 미리 확인하고, 제목이나 본문을 직접 수정할 수 있습니다. 글을 올리기 전에 오탈자 확인이나 내용 수정을 원할 때
즉시 발행 (Publish) 실시간 발행 대기 시간 없이 워드프레스에 실시간 공개(`publish` 상태)로 즉시 업로드되어 블로그 홈에 바로 글이 노출됩니다. 화제의 신작 소식을 지금 당장 블로그에 공개하고 싶을 때
예약 발행 (Schedule) 스케줄 예약 설정된 기준 시각(예: 내일 오전 09:00, 13:00 등)에 맞추어 워드프레스에 예약 대기(`future` 상태)로 등록합니다. 시간이 되면 워드프레스가 알아서 공개합니다. 블로그 저품질을 방지하고 규칙적인 시간마다 글이 올라가게 할 때
글 삭제 (Delete) 완전 삭제 내부 프로그램 데이터베이스뿐만 아니라, 워드프레스 서버에 이미 올라가 있는 예약/발행 글까지 REST API로 동시에 깨끗하게 영구 삭제합니다. 마음에 들지 않는 글이나 중복 글을 워드프레스와 함께 지울 때
4.3 워드프레스 예약 발행 메커니즘 & 시간 관리 원리
1. 미래 시간 지정 (Future Status)

프로그램이 워드프레스에 글을 보낼 때 발행 시각(Date)을 미래 시간(예: 오늘 18:00 또는 내일 09:00)으로 전송합니다. 워드프레스는 이를 감지하여 비공개 예약 보관함에 안전하게 보관합니다.

2. 워드프레스 자동 크론 (WP-Cron)

정해진 예약 시각이 도래하면 워드프레스 자체 스케줄러가 상태를 `future`에서 `publish`로 1초 만에 자동 전환하여 독자들에게 글을 공개합니다.

3. 검색엔진 실시간 호출 (IndexNow)

글이 등록되는 즉시 네이버 서치어드바이저와 Bing IndexNow API로 해당 포스트의 고유 주소(URL)를 전달하여 검색엔진 로봇이 당일 방문하도록 요청합니다.

5. 구글 애드센스 승인 및 수익화 로드맵 (Monetization & SEO)
애드센스 신청 전 필수 준비 체크리스트
  • 워드프레스 필수 4대 고정 페이지 발행: 소개(About Us), 이용약관(Terms), 개인정보처리방침(Privacy Policy), 문의(Contact)
  • 고품질 포스팅 수량: 현재 AI 템플릿 기반 글이 15~20편 이상 누적된 후 구글 애드센스 신청
  • 구글 E-E-A-T 구조 충족: 본 시스템은 에디터 평점, 인용구 박스, 추천/비추천 대조표, 쿠키영상 팁, FAQ 아코디언이 내장되어 최우수 평가를 받습니다.
내장 광고 슬롯 및 실시간 색인
  • 3대 반응형 광고 슬롯: 승인 후 애드센스 클라이언트 ID만 입력하면 상단(Top), 본문 중간(Mid), 하단(Bottom)에 자동 배치됩니다.
  • IndexNow 실시간 검색엔진 핑: 새 글 발행 즉시 네이버 서치어드바이저와 Bing 웹마스터에 알림을 전송하여 당일 빠른 색인을 유도합니다.
  • Schema.org 구조화 데이터: Google Review 및 Movie Rich Snippet 메타데이터가 자동 생성되어 검색 노출 클릭률을 높입니다.
6. 트러블슈팅 & 비상 대응 FAQ (Troubleshooting)
Q. 블로그 글씨가 흐리거나 디자인 스타일이 어긋났을 때?

바탕화면의 trendspot24_stitch_custom.css 최신 코드를 복사하여 워드프레스 [외모] → [사용자 정의하기] → [추가 CSS]에 붙여넣고 [발행]을 누르면 즉시 고대비 딥 블랙 & 레드 스타일로 복구됩니다.

Q. 워드프레스 관리자 비밀번호를 잊어버렸을 때?

워드프레스 로그인 창(비밀번호 분실 링크)에서 등록된 이메일 주소를 입력해 즉시 재설정 링크를 받으실 수 있습니다.
