새 도메인 구매 후 워드프레스 자동 포스팅 연결 4단계 가이드
1단계: 도메인 구입

가비아, 호스팅케이알, 네임칩 등에서 원하는 도메인(예: welfare24.kr)을 구매합니다.

2단계: Cloudways 워드프레스 추가

기존 Cloudways 서버(139.59.125.237)에서 [Add Application]을 눌러 새 워드프레스를 생성하고 도메인을 연결합니다. (서버 추가비용 0원)

3단계: Application Password 발급

새 워드프레스 관리자 > [사용자] > [프로필] 하단에서 새 애플리케이션 비밀번호(Application Password)를 생성합니다.

4단계: 본 페이지 등록 & 연결 테스트

우측 상단 [새 사이트 추가] 버튼을 누르고 URL과 발급받은 비밀번호를 입력 후 [연결 테스트]를 누르면 연동 끝!
