# ToonForge Desktop Studio 0.3.0

Windows용 웹툰 기획·프롬프트 제작 개발본입니다. ChatGPT와 Gemini 웹을 앱 오른쪽에 열고, 사용자가 직접 로그인한 뒤 작업합니다. 별도 API 키나 API 결제는 필요하지 않지만 각 서비스의 계정 요금제와 사용 한도는 적용됩니다.

## 사용 방법

1. 실행 폴더 안의 ToonForge.exe를 실행합니다. 실행 파일만 따로 이동하지 마세요.
2. 장르, 화풍, 캐릭터, 주제 또는 대본을 작성합니다.
3. 상단 ChatGPT 또는 Gemini 버튼으로 원하는 AI 웹을 엽니다. 두 서비스의 로그인 상태는 각각 저장됩니다.
4. 프롬프트 확인 / 입력에서 내용을 확인하고 입력창에 넣기를 누릅니다. 입력 후 사용자가 웹의 전송 버튼을 누릅니다.
5. 전체 화면으로 제작 화면에 복귀합니다. 경계선을 끌거나 방향키로 분할 비율을 조절할 수 있습니다.
6. 프로젝트 저장으로 작업을 JSON 파일로 내보낼 수 있습니다. 초안과 생성 상태는 PC에도 자동 저장됩니다.

## 0.3 수정

- Gemini를 처음 열 때 기존 대화가 표시되지 않도록 새 대화를 시도합니다. AI 화면 위의 새 대화 버튼으로 다시 시도할 수 있습니다. 기존 대화 기록은 삭제되지 않습니다.
- ChatGPT 내장 화면이 20초 넘게 멈추거나 연결에 실패하면 기본 브라우저에서 ChatGPT를 엽니다. 이 경우 프롬프트 확인 / 입력에서 복사해 브라우저 입력창에 붙여넣으세요. 브라우저 입력은 아직 자동화되지 않습니다.
- Gemini에서 새 대화 버튼이 접힌 메뉴 안에 있어도 찾도록 보완했습니다.

## 이번 버전

- ChatGPT와 Gemini 전환, 각각의 웹 세션, 각 서비스로 프롬프트 입력을 연결했습니다.
- 전환 시 작성 중인 기획을 유지하고 마지막 선택 서비스를 복원합니다.
- 기존 확장의 스토리 기획, 캐릭터 시트, 화풍, 비만화 템플릿 358종, 이미지 편집 기능을 유지했습니다.
- 초안과 회차 이력 저장을 보강했습니다.

## 검증 범위

저장 검사 4개와 데스크톱 모의 연결 검사 16개를 통과했습니다. 모의 연결은 두 AI 사이트와 같은 입력 요소로 서비스 전환, 세션 분리, 프롬프트 입력, 자동 전송 방지를 확인합니다. 실제 계정 로그인 후 전체 웹툰 생성과 이미지 수집은 아직 확인하지 못했습니다. 사이트 화면이 변경되면 자동 연결을 조정해야 할 수 있습니다.

## 남은 작업

이 폴더는 설치 마법사가 없는 개발용 실행본입니다. 기존 PC의 Electron 34.5.8 실행 환경을 재사용한 상태이므로 전용 제품 아이콘과 메타데이터, 서명된 설치 파일이 아직 없습니다. 공식 실행 환경을 준비한 뒤 설치 패키지를 만들고 실제 ChatGPT/Gemini 계정에서 기획부터 이미지 저장까지 확인해야 합니다. PDF/DOCX 추출과 신규 Director Engine은 아직 포함하지 않았습니다.

앱 데이터는 사용자 앱 데이터 폴더의 ToonForge Desktop/projects.json에 저장됩니다. 다국어 말풍선 번역을 사용하면 대사가 Google 번역 서비스로 전달됩니다. 참고한 블로그 프로그램의 기능 코드, 설정, 계정 정보는 포함하지 않았습니다.

개발 명령: npm install, npm start, npm test, npm run build:win.
