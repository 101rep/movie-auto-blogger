# 🎬 AI Shorts Remixer Studio (AI 쇼츠 리믹서 & 로컬라이저)

## 📌 개요
중국어 영상 등 다양한 소스 비디오를 AI가 자동으로 분석하여 **중국어 자막을 제거(마스킹/블러)**하고, **일레븐랩스(ElevenLabs)의 자연스러운 한국어 더빙**과 **시인성 높은 쇼츠 자막**을 입혀 **15초 세로형 숏폼(9:16 쇼츠/릴스/틱톡)**으로 완성하는 원클릭 자동화 프로그램입니다.

---

## 🚀 주요 기능
1. **AI 멀티모달 비디오 분석 & 15초 스토리보드 기획**
   - 3개 영상의 핵심 장면(후킹 -> 시연 -> 결과/CTA)을 자동으로 분할 및 최적 컷팅
   - 15초 숏폼 황금 공식에 맞춘 한국어 나레이션 대본 자동 생성
2. **중국어 자막/글씨 자동 제거 (Subtitle Cleaner)**
   - 자막 및 워터마크 영역 감지 및 스마트 블러/마스킹 처리
3. **ElevenLabs 고품질 한국어 더빙 (TTS Engine)**
   - Multilingual v2 모델 기반 자연스러운 한국어 보이스오버 생성
4. **9:16 세로 숏폼 렌더링 (Video Editor)**
   - 1080x1920 해상도, 배경 블러 레이어 및 중앙 피사체 포커스
   - 트렌디한 숏폼 스타일 한글 하이라이트 자막 자동 오버레이

---

## 💻 사용 방법

### 1. 프로그램 실행
* **GUI 모드 (추천)**: un_remixer.bat 더블 클릭
* **CLI 모드**: python main.py 실행

### 2. 폴더 구성
* 분석실/ 또는 input_videos/: 원본 MP4 영상 3개 이상 보관
* output_shorts/: 완성된 15초 세로형 쇼츠 MP4 저장
* 	emp/: 임시 오디오 및 프레임 캐시 저장
